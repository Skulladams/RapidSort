# RapidSort
Rapid Sort v1.0.6

Rapid Sort is a Kenshi inventory management mod designed to make sorting and transferring items faster and easier.

Features
Sort inventory into nearby matching storage
Sort by All, Item, or Type
Choose which item categories stay on each character
Sort from main inventory and backpack contents
Adjustable storage search radius
Per-character sorting profiles
Rapid Transfer for quickly moving items while hovering over them
Customizable hotkeys through the settings menu
Redesigned, more readable settings menu
Default Controls
[ — Run Rapid Sort
SHIFT + = — Open Rapid Sort Settings
Hold V + Hover — Transfer one item at a time
SHIFT + V + Hover — Transfer the full stack
Installation

Extract the RapidSort folder into:

Kenshi\mods\

Then enable Rapid Sort in the Kenshi launcher.
